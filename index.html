AI · Smart manufacturing

Agentic AI for Sensor Drift Mitigation

A simulation of an autonomous monitoring and self-healing system for smart manufacturing sensors. It detects drift, data quality issues and failures, then applies corrective actions through a multi-agent architecture.

  • Detects concept drift in sensor streams using ADWIN from the river library
  • Monitors data quality: missing values, spikes and frozen sensors
  • Root cause analysis and simulated self-healing: imputation, recalibration and reset
  • Real-time dashboard showing sensor streams, health scores and agent logs
PythonFastAPIriverJavaScript
View on GitHub →
ProblemSensors in manufacturing lines degrade, freeze or produce bad readings, which quietly lowers product quality.
ApproachSpecialised agents watch each stream, diagnose the likely cause from symptom patterns, and trigger a matching fix.
OutcomeA working simulation covering normal operation, wear-and-tear drift, sudden spikes, frozen sensors and missing values.
